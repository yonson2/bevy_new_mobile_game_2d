# Template issues

The work log of the template itself: past, present and future. A game made from the
template deletes `meta/` in its first issue and keeps its own tracker in `issues/`.

Same format and same tool as a game's tracker (`issues/README.md` has the rules):
`python3 tools/issues.py --dir meta/issues <command>`.
